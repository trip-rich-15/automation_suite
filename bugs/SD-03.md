# SD-03 - problem_user cannot continue from checkout step one

| Field | Value |
| --- | --- |
| ID | SD-03 |
| Scenario | The customer can enter the checkout information (features/known_defects.feature) |
| Severity | Critical |
| Priority | High |
| User | problem_user |
| Environment | saucedemo.com - Chromium - 2026-10-28 |
| Reported by | Richard Tripodi |

## Steps to reproduce

1. Open https://www.saucedemo.com
2. Log in with username problem_user and password secret_sauce
3. Add "Sauce Labs Backpack" to the cart
4. Open the cart and click Checkout
5. Enter First Name "Ana", Last Name "Lopez" and Zip/Postal Code "9410"
6. Click Continue

## Expected result

The checkout overview page (checkout-step-two.html) is displayed.

## Actual result

The page stays on checkout-step-one.html. The text typed in Last Name is written in the First Name field, so Last Name stays empty and the error "Error: Last Name is required" is displayed.

## Impact

The customer cannot complete the purchase. There is no workaround, so this blocks the main business flow of the store.
The defect is in the Last Name field: it does not keep the typed value.

## Evidence

- Test output: `Page URL expected to be '.*/checkout-step-two.html'. Actual value: https://www.saucedemo.com/checkout-step-one.html`
