# SD-01 - All products show the same image for problem_user

| Field | Value |
| --- | --- |
| ID | SD-01 |
| Scenario | Each product shows its own image (features/known_defects.feature) |
| Severity | Minor |
| Priority | Medium |
| User | problem_user |
| Environment | saucedemo.com - Chromium - 2026-10-28 |
| Reported by | Richard Tripodi |

## Steps to reproduce

1. Open https://www.saucedemo.com
2. Log in with username problem_user and password secret_sauce
3. Look at the product images on the Products page

## Expected result

Each product shows its own image.

## Actual result

The 6 products show the same image. All the images use the same file:

```
/assets/sl-404-Cq1a9k9X.jpg
```

## Impact

The customer cannot recognize the products by their image. This can cause wrong purchases and returns. The file name (404) suggests that the product images are not found and a default image is used.

## Evidence

- Test output: `AssertionError: Repeated images: ['/assets/sl-404-Cq1a9k9X.jpg', ...]` (1 unique image for 6 products)
