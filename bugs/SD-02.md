# SD-02 - Product sorting does not work for problem_user

| Field | Value |
| --- | --- |
| ID | SD-02 |
| Scenario | Products can be sorted by price (features/known_defects.feature) |
| Severity | Minor |
| Priority | Medium |
| User | problem_user |
| Environment | saucedemo.com - Chromium - 2026-10-28 |
| Reported by | Richard Tripodi |

## Steps to reproduce

1. Open https://www.saucedemo.com
2. Log in with username problem_user and password secret_sauce
3. In the sort list, select "Price (low to high)"

## Expected result

The products are shown from the lowest to the highest price:

```
7.99, 9.99, 15.99, 15.99, 29.99, 49.99
```

## Actual result

The order of the products does not change:

```
29.99, 9.99, 15.99, 49.99, 7.99, 15.99
```

## Impact

The customer cannot sort the products. The same option works with standard_user, so the problem depends on the user and not on the page. A workaround exists (look at all the products), but the sort feature does not work.

## Evidence

- Test output: `AssertionError: Wrong order for 'Price (low to high)': [29.99, 9.99, 15.99, 49.99, 7.99, 15.99]`
